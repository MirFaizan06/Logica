# Changelog

All notable changes to Logica are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[semantic versioning](https://semver.org/).

Each release needs a section here and a matching entry in
`src/content/changelog.ts`. The first feeds the GitHub release notes, the second
feeds the "What's new" sheet inside the app. `npm run check-release` checks both.

## [1.0.0] - 2026-10-18

First public release.

### Added

- 83 lessons in 26 units across three levels: Beginner, Intermediate and Advanced.
  Topics run from arguments and truth tables through syllogisms, proofs,
  quantifiers, Boolean algebra and probability to modal, temporal, epistemic and
  intuitionistic logic, metalogic, type theory, complexity and paradoxes.
- About 1,400 questions in seven formats: multiple choice, true or false, select all,
  ordering, matching, truth-table filling and classifying. Each has an explanation.
- Nineteen question generators, so drills on truth tables, equivalences, inference
  rules, syllogisms, gates, binary, sets, probability, Bayes and Kripke models do not run out.
- Study notes for every unit.
- A glossary of about 180 terms and a library of 45 fallacies, also available as flashcards.
- Placement test, unit tests and level exams with certificates.
- Daily challenge, speed round, fallacy detective, flashcards and a review queue
  for questions you got wrong.
- Truth Table Lab (tables, normal forms, equivalence and argument checks),
  Syllogism Checker with Venn diagrams, logic gate explorer, glossary, fallacy
  library and symbol sheet.
- XP, levels, daily goals, streaks with freezes, gems and 40 achievements.
- Eight themes. Four are free, four are unlocked with gems.
- Progress screen with charts, a skill map and per-topic insights.
- Local daily reminder.
- Backup and restore of all progress as text.
- In-app update check against GitHub Releases, with download, verification and
  install on Android.
